#1

Array  int[]

Primitivo
Um Array é a estrutura mais básica do Java. Tem tamanho fixo definido na criação — não cresce nem encolhe. É a base de quase todas as outras estruturas. Acesso por índice é O(1).

Como Criar

// Forma 1 — valores inline
int[] numeros = {10, 20, 30, 40, 50};

// Forma 2 — tamanho fixo, preencher depois
String[] nomes = new String[3];
nomes[0] = "Ana";
nomes[1] = "Carlos";
nomes[2] = "Maria";

// Forma 3 — objetos
Pessoa[] pessoas = new Pessoa[2];
pessoas[0] = new Pessoa("Gabriel");
TrechoSignificado
int[]Array de inteiros primitivos
new String[3]Reserva espaço para 3 Strings na memória
nomes[0]Acessa índice 0 — índices começam em 0
numeros.lengthPropriedade (não método!) que retorna o tamanho

Métodos e Operações — Arrays.*

int[] nums = {5, 3, 1, 4, 2};

// Acessar e modificar
System.out.println(nums[0]);          // → 5
nums[0] = 99;

// Percorrer
for (int n : nums) System.out.println(n);

// Ordenar (modifica o array original)
Arrays.sort(nums);                    // {1, 2, 3, 4, 5}

// Busca binária (só em array ORDENADO)
int pos = Arrays.binarySearch(nums, 3); // → índice do 3

// Copiar
int[] copia = Arrays.copyOf(nums, nums.length);
int[] faixa = Arrays.copyOfRange(nums, 1, 3); // → {2, 3}

// Preencher com um valor
Arrays.fill(nums, 0);               // {0,0,0,0,0}

// Imprimir como texto
System.out.println(Arrays.toString(nums)); // "[1, 2, 3, 4, 5]"

// Comparar dois arrays
Arrays.equals(new int[]{1,2}, new int[]{1,2}); // → true
❌ Não existe em Array
✕ nums.add(4) → Array não tem .add() — tamanho fixo
✕ nums.remove(0) → Sem .remove()
✕ nums.size() → É .length (propriedade), não .size() (método)
✕ nums.contains(1) → Sem .contains()
#2

ArrayList  List<T>

Array Dinâmico
ArrayList é um array que cresce automaticamente. Internamente usa um array, mas quando fica cheio, cria um array maior e copia tudo. Acesso por índice: O(1). Inserção/remoção no meio: O(N) — precisa deslocar os elementos.

Como Criar

import java.util.ArrayList;
import java.util.List;

// ✅ Recomendado — declarar como interface
List<String> nomes = new ArrayList<>();

// Com capacidade inicial pré-alocada (evita redimensionamentos)
List<Integer> numeros = new ArrayList<>(100);

// Já inicializado com valores
List<String> cores = new ArrayList<>(List.of("azul", "verde", "vermelho"));
TrechoSignificado
List<String>Declara pela interface — boa prática de flexibilidade
new ArrayList<>()O <> (diamond) infere o tipo da declaração automaticamente
<String>Tipo genérico — o compilador rejeita qualquer outro tipo

Métodos Disponíveis

List<String> lista = new ArrayList<>();

lista.add("Ana");                  // adiciona no final — O(1) amortizado
lista.add(1, "Bruno");             // insere na posição 1 — O(N)
lista.get(0);                      // acessa índice — O(1)
lista.set(0, "Alice");            // substitui na posição
lista.remove(1);                  // remove por índice — O(N)
lista.remove("Ana");              // remove por valor — O(N)
lista.size();                      // quantidade de elementos
lista.isEmpty();                   // true se tamanho == 0
lista.contains("Alice");         // busca linear — O(N)
lista.indexOf("Alice");          // retorna índice ou -1
lista.sort(Comparator.reverseOrder()); // ordena in-place
lista.subList(0, 2);              // visão parcial [0, 2)
lista.addAll(List.of("X", "Y"));  // adiciona coleção inteira
lista.toArray(new String[0]);    // converte para array
lista.clear();                     // remove todos
lista.forEach(n -> System.out.println(n)); // forEach + lambda
❌ Não existe em ArrayList
✕ lista.push("C") → push() é de Stack/Deque
✕ lista.poll() → poll() é de Queue
✕ lista.addFirst("X") → addFirst() é de LinkedList
✕ lista.put("k","v") → put() é de Map
💡
Regra de ouro: Declare sempre como List<T>, não como ArrayList<T>. Se precisar trocar para LinkedList depois, só muda a linha de instanciação.
#3

LinkedList  Deque<T>

Lista Encadeada
Lista duplamente encadeada. Cada elemento (nó) guarda o valor + referência para o próximo e para o anterior. Inserção/remoção no início ou fim: O(1). Acesso por índice: O(N) (precisa percorrer os nós).

[null] ← [Ana] ↔ [Carlos] ↔ [Maria] → [null]

Como Criar

import java.util.LinkedList;
import java.util.Deque;

// Como List (comportamento de lista)
List<String> lista = new LinkedList<>();

// Como Deque (fila dupla — mais comum)
Deque<String> fila = new LinkedList<>();

// Concreto (acessa TODOS os métodos específicos)
LinkedList<String> ll = new LinkedList<>();

Métodos Extras (Exclusivos do LinkedList / Deque)

LinkedList<String> ll = new LinkedList<>();

// ── INÍCIO ──────────────────────────────────────────────
ll.addFirst("primeiro");   // insere no início — O(1)
ll.offerFirst("X");        // igual ao addFirst, retorna boolean
ll.removeFirst();          // remove início — lança exceção se vazio
ll.pollFirst();            // remove início — retorna null se vazio ✅
ll.peekFirst();            // vê o início sem remover — null se vazio
ll.getFirst();             // vê o início — lança exceção se vazio

// ── FIM ─────────────────────────────────────────────────
ll.addLast("ultimo");      // insere no final — O(1)
ll.removeLast();           // remove o final
ll.pollLast();             // remove o final — null se vazio ✅
ll.peekLast();             // vê o final sem remover

// ── COMO STACK (LIFO — Last In, First Out) ──────────────
ll.push("topo");           // = addFirst
ll.pop();                  // = removeFirst
ll.peek();                 // vê o topo sem remover

// ── COMO QUEUE (FIFO — First In, First Out) ─────────────
ll.offer("novo");          // = addLast
ll.poll();                 // remove o início
ll.peek();                 // vê o início sem remover
⚖️ ArrayList vs LinkedList
→ Muitas leituras por índice → ArrayList
→ Inserção/remoção no início em O(1) → LinkedList
→ Implementar fila BFS ou pilha → LinkedList
→ Caso geral → ArrayList (melhor uso de cache da CPU)

HashSet  Set<T>

Sem Duplicatas
Coleção que não admite duplicatas. Internamente usa um HashMap. Sem ordem garantida. contains(), add() e remove() são O(1). Depende de equals() e hashCode() corretos nas chaves.

Como Criar

import java.util.HashSet;
import java.util.Set;

Set<String> set = new HashSet<>();

// Já com valores
Set<Integer> nums = new HashSet<>(Set.of(1, 2, 3));

// Eliminar duplicatas de uma lista
List<String> comDup = List.of("a", "b", "a", "c");
Set<String> semDup = new HashSet<>(comDup); // {a, b, c}

Métodos Disponíveis

Set<String> set = new HashSet<>();

// Retorna true se adicionou, false se já existia
boolean ok  = set.add("Ana");    // → true
boolean dup = set.add("Ana");    // → false (duplicata ignorada)

set.contains("Ana");            // → true — O(1) ← SUPERPOWER
set.remove("Ana");              // retorna true se removeu
set.size();
set.isEmpty();
set.clear();

// Percorrer (sem ordem garantida)
for (String s : set) System.out.println(s);

// ── OPERAÇÕES DE CONJUNTO ────────────────────────────────
Set<String> a = new HashSet<>(Set.of("x", "y", "z"));
Set<String> b = new HashSet<>(Set.of("y", "z", "w"));

a.addAll(b);     // União      → {x, y, z, w}
a.retainAll(b);  // Interseção → {y, z, w}
a.removeAll(b);  // Diferença  → {x}
❌ Não existe em HashSet
✕ set.get(0) → Set não tem acesso por índice
✕ set.add(0, "X") → Sem inserção em posição específica
✕ set.indexOf("Ana") → Sem índices em Set
✕ set.first() / set.last() → Sem ordem → impossível "primeiro" ou "último"
⚠️
Atenção ao hashCode/equals: Se você usar objetos personalizados (ex: Pessoa) sem sobrescrever equals() e hashCode(), dois objetos com os mesmos dados serão tratados como diferentes pelo HashSet!
#5

LinkedHashSet  Set<T>

Sem Dup + Ordem
Igual ao HashSet (sem duplicatas, O(1) para contains/add/remove), mas mantém a ordem de inserção na iteração. Usa mais memória por manter a lista encadeada internamente. 
Set<String> set = new LinkedHashSet<>();
set.add("Banana");
set.add("Maçã");
set.add("Uva");
set.add("Banana"); // duplicata ignorada

for (String s : set) System.out.println(s);
// Banana  ← mantém ordem de inserção
// Maçã
// Uva
⚖️ HashSet vs LinkedHashSet
→ Só quer unicidade, ordem não importa → HashSet (levemente mais rápido)
→ Precisa unicidade E manter ordem de inserção → LinkedHashSet
ℹ️
Métodos: Exatamente os mesmos do HashSet. A única diferença é comportamental — a ordem de inserção é preservada na iteração.
#6

TreeSet  SortedSet<T>

Ordenado Naturalmente
Set que mantém os elementos ordenados automaticamente (ordem natural ou por Comparator). Internamente usa uma árvore Red-Black. Todas as operações são O(log N).

Como Criar

// Ordem natural (Integer: crescente; String: alfabética)
SortedSet<Integer> ts = new TreeSet<>();
ts.add(5); ts.add(1); ts.add(3);
// Internamente: {1, 3, 5}

// Ordem customizada com Comparator
TreeSet<Integer> dec = new TreeSet<>(Comparator.reverseOrder());
// {5, 3, 1}

Métodos Exclusivos de Navegação

TreeSet<Integer> ts = new TreeSet<>(Set.of(10, 20, 30, 40, 50));

ts.first();          // → 10  — menor elemento
ts.last();           // → 50  — maior elemento

ts.lower(30);        // → 20  — maior elemento MENOR que 30
ts.floor(30);        // → 30  — maior elemento MENOR OU IGUAL a 30
ts.higher(30);       // → 40  — menor elemento MAIOR que 30
ts.ceiling(30);      // → 30  — menor elemento MAIOR OU IGUAL a 30

ts.subSet(20, 40);   // → {20, 30}  — de 20 incluso a 40 excluso
ts.headSet(30);     // → {10, 20}  — do início até 30 excluso
ts.tailSet(30);     // → {30, 40, 50} — de 30 incluso até o fim
🔑
TreeSet requer Comparable: Ao usar objetos personalizados, eles devem implementar Comparable<T> ou você deve passar um Comparator no construtor — caso contrário, ocorre ClassCastException em runtime.

HashMap  Map<K,V>

Chave → Valor
Estrutura chave → valor. Cada chave é única. A chave é hasheada para encontrar a posição do valor. Busca por chave: O(1). Sem ordem garantida. Depende de equals() e hashCode() nas chaves.

Como Criar

import java.util.HashMap;
import java.util.Map;

Map<String, Integer> idades = new HashMap<>();

// Já inicializado (Java 9+)
Map<String, Integer> cfg = new HashMap<>(Map.of(
    "timeout", 30,
    "maxRetry", 3
));

// Mapa de String para Lista
Map<String, List<String>> grupos = new HashMap<>();

Métodos Disponíveis

Map<String, Integer> m = new HashMap<>();

m.put("Ana", 25);                  // insere ou substitui
m.get("Ana");                      // → 25 — O(1)
m.get("Zé");                       // → null se não existe
m.getOrDefault("Zé", 0);          // → 0 (evita null)
m.containsKey("Ana");             // → true — O(1)
m.containsValue(25);              // → true — O(N)
m.remove("Ana");                   // remove pela chave
m.remove("Ana", 99);               // remove só se valor == 99
m.putIfAbsent("Novo", 99);         // insere só se chave não existir
m.size(); m.isEmpty(); m.clear();

// ── PERCORRER ───────────────────────────────────────────
for (Map.Entry<String, Integer> e : m.entrySet()) {
    System.out.println(e.getKey() + " → " + e.getValue());
}
m.forEach((k, v) -> System.out.println(k + ": " + v));

// ── PADRÕES AVANÇADOS ────────────────────────────────────
// Contador de frequências (muito usado em entrevista)
m.merge("Ana", 1, Integer::sum);   // Ana=0 → 1; Ana=1 → 2

// Criar lista se chave não existir
Map<String, List<String>> g = new HashMap<>();
g.computeIfAbsent("time_a", k -> new ArrayList<>()).add("Ana");
❌ Não existe em HashMap
✕ m.get(0) → get() recebe a CHAVE, não um índice inteiro
✕ m.add("Ana", 25) → em Map é put(), não add()
✕ m.remove(0) → remove() recebe a CHAVE
✕ m.first() / m.last() → sem ordem, esses são do TreeMap
⚠️
Contrato hashCode/equals nas Chaves: Se usar objetos personalizados como chave, sem sobrescrever hashCode() e equals(), você jamais encontrará o valor depois de inserir — é como criar uma gaveta sem rótulo.
#8

LinkedHashMap  Map<K,V>

Chave-Valor + Ordem
Igual ao HashMap (chave única, O(1) para get/put/remove), mas mantém a ordem de inserção na iteração. 
Map<String, Integer> m = new LinkedHashMap<>();
m.put("Banana", 3);
m.put("Maçã", 1);
m.put("Uva", 5);

for (Map.Entry<String, Integer> e : m.entrySet()) {
    System.out.println(e.getKey() + ": " + e.getValue());
}
// Banana: 3  ← ordem de inserção garantida
// Maçã: 1
// Uva: 5
⚖️ HashMap vs LinkedHashMap
→ Ordem não importa → HashMap
→ Precisa de ordem de inserção → LinkedHashMap
→ Cache LRU (remover mais antigo) → LinkedHashMap com construtor especial
#9

TreeMap  SortedMap<K,V>

Chaves Ordenadas
Map onde as chaves são mantidas em ordem natural (ou por Comparator). Internamente usa árvore Red-Black. Todas as operações são O(log N). Permite navegação pelas chaves.

Métodos Exclusivos de Navegação

TreeMap<Integer, String> tm = new TreeMap<>();
tm.put(10, "dez"); tm.put(30, "trinta");
tm.put(20, "vinte"); tm.put(40, "quarenta");

tm.firstKey();          // → 10  — menor chave
tm.lastKey();           // → 40  — maior chave

tm.lowerKey(30);        // → 20  — maior chave MENOR que 30
tm.floorKey(30);        // → 30  — maior chave MENOR OU IGUAL a 30
tm.higherKey(30);       // → 40  — menor chave MAIOR que 30
tm.ceilingKey(20);      // → 20  — menor chave MAIOR OU IGUAL a 20

tm.firstEntry();        // → {10="dez"}  — entrada completa
tm.lastEntry();         // → {40="quarenta"}

tm.subMap(20, 40);      // → {20="vinte", 30="trinta"}
tm.headMap(30);        // → {10="dez", 20="vinte"}
tm.tailMap(30);        // → {30="trinta", 40="quarenta"}
ℹ️
Quando usar TreeMap? Quando precisar manter chaves ordenadas e fazer consultas por faixa — ex: "todos os registros entre a data X e Y" ou "todas as chaves maiores que K".

Padrões de Entrevista

🔴 1. Contador de Frequências — Two Sum, Group Anagrams, Ransom Note
Map<Character, Integer> freq = new HashMap<>();
for (char c : "banana".toCharArray()) {
    freq.merge(c, 1, Integer::sum);
}
// {b=1, a=3, n=2}
🟡 2. Eliminar Duplicatas Mantendo Ordem
List<String> comDup = List.of("a", "b", "a", "c", "b");
Set<String> semDup = new LinkedHashSet<>(comDup);
// [a, b, c] — mantém ordem de inserção
🟢 3. Verificar Elemento Já Visto — Contains Duplicate
Set<Integer> vistos = new HashSet<>();
int[] nums = {1, 2, 3, 1};
for (int n : nums) {
    if (!vistos.add(n)) {
        System.out.println("Duplicata: " + n); // → 1
    }
}
🔵 4. Agrupar por Categoria — Group Anagrams
Map<String, List<String>> grupos = new HashMap<>();
String[] palavras = {"eat", "tea", "tan", "ate", "nat", "bat"};
for (String p : palavras) {
    char[] chars = p.toCharArray();
    Arrays.sort(chars);
    String chave = new String(chars); // anagrama ordenado
    grupos.computeIfAbsent(chave, k -> new ArrayList<>()).add(p);
}
// {aet=[eat, tea, ate], ant=[tan, nat], abt=[bat]}
